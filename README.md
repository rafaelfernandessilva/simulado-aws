# Simulado AWS SAA-C03

Simulador em português com 361 questões, seleção por bloco e domínio, quantidade personalizável e gabarito comentado ao finalizar.

## Executar

Abra o arquivo index.html no navegador. Os arquivos index.html, style.css, app.js e questions.js devem ficar na mesma pasta.

## Publicar no GitHub Pages

Após fazer o commit e o push para a branch main, abra Settings → Pages no repositório.

Em Build and deployment, selecione Deploy from a branch. Escolha main e /(root) e clique em Save.

O endereço publicado aparecerá nessa mesma página. O arquivo .nojekyll permite servir os arquivos estáticos diretamente.

## Conteúdo

As questões foram fornecidas pelo usuário. Os gabaritos, as explicações e as notas das alternativas foram revisados com a documentação oficial da AWS entre 25 e 27 de novembro de 2026. As referências aparecem na revisão de cada questão ao finalizar o simulado.

O histórico das correções e as fontes de todas as 361 questões estão em [AUDITORIA-QUESTOES.md](AUDITORIA-QUESTOES.md).
